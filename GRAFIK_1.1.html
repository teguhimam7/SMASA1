❓ FAQ — Pertanyaan yang Sering Diajukan

1. Apa itu web AWS EcoSkola ini? ▾
Web ini adalah dashboard pemantauan stasiun cuaca otomatis (Automatic Weather Station) milik SMA Darul Ulum 1 Unggulan BPPT Jombang. Modul ESP32 membaca 6 sensor, yaitu suhu, kelembapan, intensitas cahaya, api, jarak ultrasonik, dan hujan. Datanya dikirim lewat Wi-Fi ke database Supabase, lalu ditampilkan di web ini secara real-time dalam bentuk kartu angka dan grafik.
2. Bagaimana cara membaca data di web ini? ▾

Indikator status (kanan atas): LIVE berarti data sedang masuk, MENUNGGU DATA berarti data terlambat, dan OFFLINE berarti sudah lama tidak ada data sama sekali.

Kartu sensor: menampilkan nilai terbaru tiap sensor: suhu (°C), kelembapan (%), cahaya (ADC), jarak (cm), dan hujan (%). Pada sensor api, nilai ADC yang rendah berarti api terdeteksi, dan tulisan status di kartu akan berubah.

Grafik telemetri: menampilkan 12 data terakhir. Sumbu mendatar adalah jam pengiriman, sumbu tegak adalah nilai sensor. Klik sebuah kartu atau tombol di atas grafik untuk berpindah ke sensor lain.

Jam: ditampilkan dalam zona waktu GMT+7 (WIB).
