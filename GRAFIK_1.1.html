❓ FAQ — Pertanyaan yang Sering Diajukan

1. Apa itu web AWS EcoSkola ini? ▾
Web ini adalah dashboard pemantauan stasiun cuaca otomatis (Automatic Weather Station) milik SMA Darul Ulum 1 Unggulan BPPT Jombang. Modul ESP32 membaca 6 sensor (DHT11, LDR, api, ultrasonik, hujan, dan UV) yang menghasilkan 8 data: suhu, kelembapan, hujan, cahaya, api, jarak, UV index, dan tegangan UV. Datanya dikirim lewat Wi-Fi ke database Supabase, lalu ditampilkan di web ini secara real-time dalam bentuk kartu angka dan grafik.
